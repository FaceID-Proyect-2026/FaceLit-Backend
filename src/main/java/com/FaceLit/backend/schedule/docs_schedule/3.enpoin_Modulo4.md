# Endpoints y JSON de prueba - FaceLit Backend

# Módulo: Gestión de Horarios

## BASE URL

```text
http://localhost:8080
```

---

# 1. REGISTRAR HORARIO

### Endpoint

```http
POST /api/admin/schedules
```

### Headers

```text
Authorization: Bearer TOKEN_ADMIN_O_COORDINATOR
Content-Type: application/json
```

### JSON

```json
{
  "idChip": "UUID_DE_LA_FICHA",
  "idEnvironment": "UUID_DEL_AMBIENTE",
  "idInstructor": "UUID_DEL_INSTRUCTOR",
  "dayOfWeek": "LUNES",
  "startTime": "08:00:00",
  "endTime": "10:00:00"
}
```

### Respuesta esperada

### HTTP STATUS

```text
201 CREATED
```

### Response

```json
{
  "idSchedule": "uuid-generado",
  "chipName": "Ficha ADSO 2025",
  "environmentName": "Ambiente 101",
  "instructorName": "Carlos Gomez",
  "dayOfWeek": "LUNES",
  "startTime": "08:00:00",
  "endTime": "10:00:00",
  "status": "ACTIVE",
  "message": "Horario registrado correctamente"
}
```

# 2. ACTUALIZAR HORARIO

### Endpoint

```http
PUT /api/admin/schedules/{UUID_DEL_HORARIO}
```

### Headers

```text
Authorization: Bearer TOKEN_ADMIN_O_COORDINATOR
Content-Type: application/json
```

### JSON

```json
{
  "idChip": "UUID_DE_LA_FICHA",
  "idEnvironment": "UUID_NUEVO_AMBIENTE",
  "idInstructor": "UUID_NUEVO_INSTRUCTOR",
  "dayOfWeek": "LUNES",
  "startTime": "10:00:00",
  "endTime": "12:00:00"
}
```

### Respuesta esperada

### HTTP STATUS

```text
200 OK
```

### Response

```json
{
  "idSchedule": "uuid-del-horario",
  "chipName": "Ficha ADSO 2025",
  "environmentName": "Ambiente 102",
  "instructorName": "Ana Torres",
  "dayOfWeek": "LUNES",
  "startTime": "10:00:00",
  "endTime": "12:00:00",
  "status": "ACTIVE",
  "message": "Horario actualizado correctamente"
}
```

# 3. ELIMINAR HORARIO

### Endpoint

```http
DELETE /api/admin/schedules/{UUID_DEL_HORARIO}
```

### Headers

```text
Authorization: Bearer TOKEN_ADMIN_O_COORDINATOR
```

### Respuesta esperada

### HTTP STATUS

```text
204 NO CONTENT
```

Sin body.

### Posibles respuestas de error

#### Horario no encontrado

```json
{
  "message": "Horario no encontrado"
}
```

#### Horario ya inactivo

```json
{
  "message": "El horario ya está inactivo"
}
```

# Validaciones de Cruce de Horarios

## 1. Ambiente ocupado en la misma franja

### JSON

```json
{
  "idChip": "UUID_OTRA_FICHA",
  "idEnvironment": "UUID_MISMO_AMBIENTE",
  "idInstructor": "UUID_OTRO_INSTRUCTOR",
  "dayOfWeek": "LUNES",
  "startTime": "09:00:00",
  "endTime": "11:00:00"
}
```

### Respuesta esperada

```json
{
  "message": "El ambiente ya está asignado para esta franja"
}
```

# Resumen de Casos de Prueba

| Caso | Resultado esperado |
|------|---------------------|
| Registrar horario correctamente | 201 CREATED |
| Actualizar horario | 200 OK |
| Eliminar horario | 204 NO CONTENT |
| Consultar horarios de una ficha | 200 OK |
| Consultar todos los horarios | 200 OK |
| Cruce de ambiente | "El ambiente ya está asignado para esta franja" |
| Cruce de instructor | "El instructor ya tiene clase en esta franja" |
| Cruce de ficha | "La ficha ya tiene un horario en esta franja" |

| Ambiente inexistente | "Ambiente no encontrado" |
| Instructor inexistente | "Instructor no encontrado" |
| Horario ya inactivo | "El horario ya está inactivo" |
| Sin token | 403 FORBIDDEN |
| Token sin permisos | 403 FORBIDDEN |
