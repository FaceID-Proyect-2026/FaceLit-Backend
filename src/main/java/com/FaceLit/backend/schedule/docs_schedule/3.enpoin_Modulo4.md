# Endpoints y JSON de prueba - FaceLit Backend

# Módulo: Gestión de Horarios

## BASE URL

```text
http://localhost:8080
```

---

# 1. REGISTRAR HORARIO

### Endpoint

```http
POST /api/admin/schedules
```

### Headers

```text
Authorization: Bearer TOKEN_ADMIN_O_COORDINATOR
Content-Type: application/json
```

### JSON

```json
{
  "idChip": "UUID_DE_LA_FICHA",
  "idEnvironment": "UUID_DEL_AMBIENTE",
  "idInstructor": "UUID_DEL_INSTRUCTOR",
  "dayOfWeek": "LUNES",
  "startTime": "08:00:00",
  "endTime": "10:00:00"
}
```

### Respuesta esperada

### HTTP STATUS

```text
201 CREATED
```

### Response

```json
{
  "idSchedule": "uuid-generado",
  "chipName": "Ficha ADSO 2025",
  "environmentName": "Ambiente 101",
  "instructorName": "Carlos Gomez",
  "dayOfWeek": "LUNES",
  "startTime": "08:00:00",
  "endTime": "10:00:00",
  "status": "ACTIVE",
  "message": "Horario registrado correctamente"
}
```

# 3. ELIMINAR HORARIO

### Endpoint

```http
DELETE /api/admin/schedules/{UUID_DEL_HORARIO}
```

### Headers

```text
Authorization: Bearer TOKEN_ADMIN_O_COORDINATOR
```

### Respuesta esperada

### HTTP STATUS

```text
204 NO CONTENT
```

Sin body.

### Posibles respuestas de error

#### Horario no encontrado

```json
{
  "message": "Horario no encontrado"
}
```

#### Horario ya inactivo

```json
{
  "message": "El horario ya está inactivo"
}
```
