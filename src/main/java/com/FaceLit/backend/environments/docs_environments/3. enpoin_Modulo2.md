# Endpoints y JSON de prueba - FaceLit Backend

## Módulo: Environment (Ambientes)

### BASE URL

```
http://localhost:8080
```

---

# 1. REGISTRAR AMBIENTE

### Endpoint

```
POST /api/admin/environments
```

### Headers

```
Authorization: Bearer TOKEN
Content-Type: application/json
```

### JSON

```json
{
  "environmentName": "Ambiente 101",
  "capacity": 30,
  "status": "ACTIVE"
}
```

### Respuesta esperada

### HTTP STATUS

```
201 CREATED
```

### Response

```json
{
  "idEnvironment": "8f97e3d2-7b5a-4c1f-a9d8-2c0c2d38d6a7",
  "environmentName": "Ambiente 101",
  "capacity": 30,
  "status": "ACTIVE"
}
```

---

# 2. BUSCAR AMBIENTE POR NOMBRE

### Endpoint

```
GET /api/admin/environments/search?name=Ambiente 101
```

### Headers

```
Authorization: Bearer TOKEN
```

### Respuesta esperada

### HTTP STATUS

```
200 OK
```

### Response

```json
[
  {
    "idEnvironment": "8f97e3d2-7b5a-4c1f-a9d8-2c0c2d38d6a7",
    "environmentName": "Ambiente 101",
    "capacity": 30,
    "status": "ACTIVE"
  }
]
```
