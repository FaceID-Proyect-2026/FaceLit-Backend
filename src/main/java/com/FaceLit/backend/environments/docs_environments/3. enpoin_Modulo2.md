# Endpoints y JSON de prueba - FaceLit Backend

## Módulo: Environment (Ambientes)

### BASE URL

```
http://localhost:8080
```

---

# 1. REGISTRAR AMBIENTE

### Endpoint

```
POST /api/admin/environments
```

### Headers

```
Authorization: Bearer TOKEN
Content-Type: application/json
```

### JSON

```json
{
  "environmentName": "Ambiente 101",
  "capacity": 30,
  "status": "ACTIVE"
}
```

### Respuesta esperada

### HTTP STATUS

```
201 CREATED
```

### Response

```json
{
  "idEnvironment": "8f97e3d2-7b5a-4c1f-a9d8-2c0c2d38d6a7",
  "environmentName": "Ambiente 101",
  "capacity": 30,
  "status": "ACTIVE"
}
```

# 5. ELIMINAR AMBIENTE (ELIMINACIÓN LÓGICA)

### Endpoint

```
DELETE /api/admin/environments/{UUID_DEL_AMBIENTE}
```

### Headers

```
Authorization: Bearer TOKEN
```

### Respuesta esperada

### HTTP STATUS

```
204 NO CONTENT
```

### Response

```
Sin contenido (No Content)
```

### Validaciones

- Si el UUID no existe:

```json
{
  "message": "Ambiente no encontrado"
}
```

- Si el ambiente ya está inactivo:

```json
{
  "message": "El ambiente ya está inactivo"
}
```

---

# 6. LISTADO PAGINADO DE AMBIENTES

### Endpoint

```
GET /api/admin/environments/paged?page=0&size=10
```

### Headers

```
Authorization: Bearer TOKEN
```

### Parámetros

| Parámetro | Tipo | Descripción |
|-----------|------|-------------|
| page | Integer | Número de página (empieza en 0) |
| size | Integer | Cantidad de registros por página |

### Respuesta esperada

### HTTP STATUS

```
200 OK
```

### Response

```json
{
  "content": [
    {
      "idEnvironment": "8f97e3d2-7b5a-4c1f-a9d8-2c0c2d38d6a7",
      "environmentName": "Ambiente 101",
      "capacity": 30,
      "status": "ACTIVE"
    },
    {
      "idEnvironment": "1c45276d-6e2b-4cf4-8e67-3a4c85d81b91",
      "environmentName": "Laboratorio 202",
      "capacity": 25,
      "status": "ACTIVE"
    }
  ],
  "totalElements": 5,
  "totalPages": 1,
  "number": 0,
  "size": 10
}
```
