# Endpoints y JSON de prueba - FaceLit Backend

## Módulo: Environment (Ambientes)

### BASE URL

```
http://localhost:8080
```

---

# 1. REGISTRAR AMBIENTE

### Endpoint

```
POST /api/admin/environments
```

### Headers

```
Authorization: Bearer TOKEN
Content-Type: application/json
```

### JSON

```json
{
  "environmentName": "Ambiente 101",
  "capacity": 30,
  "status": "ACTIVE"
}
```

### Respuesta esperada

### HTTP STATUS

```
201 CREATED
```

### Response

```json
{
  "idEnvironment": "8f97e3d2-7b5a-4c1f-a9d8-2c0c2d38d6a7",
  "environmentName": "Ambiente 101",
  "capacity": 30,
  "status": "ACTIVE"
}
```

---

# 2. BUSCAR AMBIENTE POR NOMBRE

### Endpoint

### Headers

# 5. ELIMINAR AMBIENTE (ELIMINACIÓN LÓGICA)

### Endpoint

```
DELETE /api/admin/environments/{UUID_DEL_AMBIENTE}
```

### Headers

```
Authorization: Bearer TOKEN
```

### Respuesta esperada

### HTTP STATUS

```
204 NO CONTENT
```

### Response

```
Sin contenido (No Content)
```

### Validaciones

- Si el UUID no existe:

```json
{
  "message": "Ambiente no encontrado"
}
```

- Si el ambiente ya está inactivo:

```json
{
  "message": "El ambiente ya está inactivo"
}
```

---

# 6. LISTADO PAGINADO DE AMBIENTES

### Endpoint

```
GET /api/admin/environments/paged?page=0&size=10
```

### Headers

```
Authorization: Bearer TOKEN
```

### Parámetros

| Parámetro | Tipo | Descripción |
|-----------|------|-------------|
| page | Integer | Número de página (empieza en 0) |
| size | Integer | Cantidad de registros por página |

### Respuesta esperada

### HTTP STATUS

```
200 OK
```

# Endpoints y JSON de prueba - FaceLit Backend

# Módulo: Chip Environment (Asignación de Fichas a Ambientes)

## BASE URL

```
http://localhost:8080
```

---

# 1. ASIGNAR FICHA A UN AMBIENTE

## Endpoint

```
POST /api/admin/chip-environments
```

## Headers

```
Authorization: Bearer TOKEN
Content-Type: application/json
```

## JSON

```json
{
  "idChip": "UUID_DE_LA_FICHA",
  "idEnvironment": "UUID_DEL_AMBIENTE",
  "assignmentDate": "2026-07-07"
}
```

## Respuesta esperada

### HTTP STATUS

```
201 CREATED
```

### Response

```json
{
  "idChipEnvironment": "uuid-generado",
  "idChip": "uuid-de-la-ficha",
  "chipName": "Ficha ADSO 2025",
  "idEnvironment": "uuid-del-ambiente",
  "environmentName": "Ambiente 101",
  "assignmentDate": "2026-07-07",
  "status": "ACTIVE",
  "message": "Ficha asignada al ambiente correctamente"
}
```

---

# 2. INTENTAR ASIGNAR LA MISMA FICHA AL MISMO AMBIENTE

## Endpoint

```
POST /api/admin/chip-environments
```

## Headers

```
Authorization: Bearer TOKEN
Content-Type: application/json
```

## JSON

```json
{
  "idChip": "UUID_DE_LA_MISMA_FICHA",
  "idEnvironment": "UUID_DEL_MISMO_AMBIENTE",
  "assignmentDate": "2026-07-07"
}
```

## Respuesta esperada

### HTTP STATUS

```
409 CONFLICT
```

### Response

```json
{
  "message": "Esta ficha ya está asignada a ese ambiente"
}
```

# 5. ELIMINAR UNA ASIGNACIÓN (ELIMINACIÓN LÓGICA)

## Endpoint

```
DELETE /api/admin/chip-environments/{UUID_DE_LA_ASIGNACION}
```

## Headers

```
Authorization: Bearer TOKEN
```

## Respuesta esperada

### HTTP STATUS

```
204 NO CONTENT
```

### Response

```
Sin contenido (No Content)
```

### Validaciones

#### Si la asignación no existe

```json
{
  "message": "Asignacion no encontrada"
}
```

#### Si la asignación ya está inactiva

```json
{
  "message": "La asignacion ya está inactiva"
}
```

---

# Validaciones Generales

## 1. Ficha inexistente

### Resultado esperado

```json
{
  "message": "Ficha no encontrada"
}
```

---

## 2. Ambiente inexistente

### Resultado esperado

```json
{
  "message": "Ambiente no encontrado"
}
```

---

## 3. Asignación duplicada

### Resultado esperado

```json
{
  "message": "Esta ficha ya está asignada a ese ambiente"
}
```

---

## 4. Campos vacíos

### HTTP STATUS

```
400 BAD REQUEST
```

### Resultado esperado

```json
{
  "message": "Los campos obligatorios son requeridos"
}
```

*(El mensaje puede variar según las validaciones implementadas.)*

---

## 5. Sin token

### HTTP STATUS

```
403 FORBIDDEN
```

### Resultado esperado

```json
{
  "message": "Access Denied"
}
```

---

## 6. Token de INSTRUCTOR

### HTTP STATUS

```
403 FORBIDDEN
```

### Resultado esperado

```json
{
  "message": "Access Denied"
}
```

---

# Resumen de Casos de Prueba

| Caso | Resultado esperado |
|------|---------------------|
| Asignar ficha correctamente | 201 CREATED |
| Asignación duplicada | 409 CONFLICT |
| Consultar fichas por ambiente | 200 OK |
| Consultar ambientes por ficha | 200 OK |
| Eliminar asignación | 204 NO CONTENT |
| idChip inexistente | "Ficha no encontrada" |
| idEnvironment inexistente | "Ambiente no encontrado" |
| Asignación inexistente | "Asignacion no encontrada" |
| Asignación ya inactiva | "La asignacion ya está inactiva" |
| Campos vacíos | 400 BAD REQUEST |
| Sin token | 403 FORBIDDEN |
| Token con rol INSTRUCTOR | 403 FORBIDDEN |
