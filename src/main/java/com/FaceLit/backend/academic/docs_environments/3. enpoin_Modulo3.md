## 1. Módulo: Programas de Formación

### 1.1 Registrar Programa

**Endpoint**

```http
POST /api/admin/programs
```

**Headers**

```text
Authorization: Bearer TOKEN_ADMIN_O_COORDINATOR
Content-Type: application/json
```

**JSON**

```json
{
  "programName": "Análisis y Desarrollo de Software",
  "state": "ACTIVE"
}
```

**Respuesta esperada**

HTTP STATUS

```text
201 CREATED
```

Response

```json
{
  "idProgram": "8b2b4c9d-2c6f-4d58-9d4f-f0f1a95f7f63",
  "programName": "Análisis y Desarrollo de Software",
  "state": "ACTIVE",
  "message": "Programa registrado correctamente"
```

|------|--------------------|

## 2. Módulo: Eliminación Permanente de Programas

### BASE URL

```text
http://localhost:8080
```

### 2.1 Flujo de Eliminación Permanente de un Programa

> **Importante:** Un programa solo puede eliminarse permanentemente si previamente fue inactivado.

---

### 2.2 Inactivar Programa

**Endpoint**

```http
DELETE /api/admin/programs/{UUID_DEL_PROGRAMA}
```

**Headers**

```text
Authorization: Bearer TOKEN_ADMIN_O_COORDINATOR
```

**Respuesta esperada**

HTTP STATUS

```text
204 NO CONTENT
```

Sin body.

> Después de esta operación el programa queda con estado **INACTIVE**.

---

### 2.3 Eliminar Permanentemente el Programa

**Endpoint**

```http
DELETE /api/admin/programs/{UUID_DEL_PROGRAMA}/permanent
```

**Headers**

```text
Authorization: Bearer TOKEN_ADMIN_O_COORDINATOR
```

**Respuesta esperada**

HTTP STATUS

```text
204 NO CONTENT
```

Sin body.

> El programa es eliminado definitivamente de la base de datos.

---

### 2.4 Validaciones para Probar

| Caso | Respuesta esperada |
|------|--------------------|
| Programa aún activo | `"El programa debe estar inactivo antes de eliminarse permanentemente"` |
| Programa inexistente | `"Programa no encontrado"` |
| Programa asociado a fichas | `"No es posible eliminar el programa porque tiene registros asociados"` *(si aplica)* |
| UUID inválido | `400 Bad Request` |
| Sin token | `403 Forbidden` |
| Token de INSTRUCTOR | `403 Forbidden` |

---

### 2.5 Flujo de Prueba

**Paso 1 - Inactivar programa**

```http
DELETE http://localhost:8080/api/admin/programs/{UUID_DEL_PROGRAMA}
Authorization: Bearer TOKEN_ADMIN_O_COORDINATOR
```

Resultado esperado

```text
204 NO CONTENT
```

Estado:

```text
INACTIVE
```

**Paso 2 - Eliminar permanentemente**

```http
DELETE http://localhost:8080/api/admin/programs/{UUID_DEL_PROGRAMA}/permanent
Authorization: Bearer TOKEN_ADMIN_O_COORDINATOR
```

Resultado esperado

```text
204 NO CONTENT
```

Resultado:

```text
El programa fue eliminado permanentemente de la base de datos.
```

### 5.7 Flujo Completo de Prueba

**Paso 1 - Iniciar sesión como COORDINATOR**

Obtiene:

```
TOKEN_COORDINATOR
```

**Paso 2 - Crear un programa**

Endpoint

```http
POST /api/admin/programs
```

**Paso 3 - Crear una ficha**

Endpoint

```http
POST /api/admin/chips
```

Guardar el valor generado en:

```
chipCode
```

**Paso 4 - Iniciar sesión como APPRENTICE**

Obtiene:

```
TOKEN_APPRENTICE
```

**Paso 5 - Unirse a la ficha**

Endpoint

```http
POST /api/apprentice/join-chip
```

Usando el `chipCode` obtenido anteriormente.

**Paso 6 - Consultar mis fichas**

Endpoint

```http
GET /api/apprentice/my-chips
```

Verificar que la asociación fue creada correctamente.

**Paso 7 - Iniciar sesión nuevamente como COORDINATOR**

Obtiene:

```
TOKEN_COORDINATOR
```

**Paso 8 - Consultar los aprendices de la ficha**

Endpoint

```http
GET /api/admin/chips/{id}/apprentices
```

Verificar que el aprendiz aparece en el listado.

**Paso 9 - Desvincular al aprendiz**

Endpoint

```http
DELETE /api/admin/user-chips/{idUserChip}
```

Verificar que la asignación queda inactiva.

**Paso 10 - Iniciar sesión nuevamente como APPRENTICE**

Intentar unirse a otra ficha.

Resultado esperado:

El sistema permite el registro porque la asignación anterior fue desvinculada.

---

### 5.8 Resumen de Casos de Prueba

| Caso | Resultado esperado |
|------|---------------------|
| Unirse a una ficha correctamente | 201 CREATED |
| Consultar mis fichas | 200 OK |
| Consultar aprendices de una ficha | 200 OK |
| Desvincular aprendiz de una ficha | 204 NO CONTENT |
| Código de ficha inexistente | "El código de ficha no existe o no está activo" |
| Ficha inactiva | "La ficha ya no está disponible para nuevos registros" |
| Aprendiz ya vinculado a otra ficha | "Ya estás vinculado a una ficha activa. Contacta al administrador para desvincular" |
| Código vacío | 400 BAD REQUEST |
| UUID de asignación inexistente | "Asignacion no encontrada" |
| Asignación ya inactiva | "Esta asignacion ya está inactiva" |
| Token APPRENTICE en rutas Admin | 403 FORBIDDEN |
| Token COORDINATOR en rutas Admin | 200 OK |
| Sin token | 403 FORBIDDEN |
