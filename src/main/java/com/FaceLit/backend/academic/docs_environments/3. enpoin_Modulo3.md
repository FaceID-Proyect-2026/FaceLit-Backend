# Endpoints y JSON de prueba - FaceLit Backend

## Módulo: Programas de Formación

### BASE URL

```text
http://localhost:8080
```

---

# 1. REGISTRAR PROGRAMA

### Endpoint

```http
POST /api/admin/programs
```

### Headers

```text
Authorization: Bearer TOKEN_ADMIN_O_COORDINATOR
Content-Type: application/json
```

### JSON

```json
{
  "programName": "Análisis y Desarrollo de Software",
  "state": "ACTIVE"
}
```

### Respuesta esperada

### HTTP STATUS

```text
201 CREATED
```

### Response

```json
{
  "idProgram": "8b2b4c9d-2c6f-4d58-9d4f-f0f1a95f7f63",
  "programName": "Análisis y Desarrollo de Software",
  "state": "ACTIVE",
  "message": "Programa registrado correctamente"
}
```

# 3. ELIMINAR (INACTIVAR) PROGRAMA

### Endpoint

```http
DELETE /api/admin/programs/{UUID_DEL_PROGRAMA}
```

### Headers

```text
Authorization: Bearer TOKEN_ADMIN_O_COORDINATOR
```

### Respuesta esperada

### HTTP STATUS

```text
204 NO CONTENT
```

Sin body.

### Posibles respuestas de error

```json
{
  "message": "Programa no encontrado"
}
```

```json
{
  "message": "El programa ya está inactivo"
}
```

# Validaciones a probar

| Caso | Respuesta esperada |
|------|--------------------|
| Nombre duplicado en POST | `"Ya existe un programa con ese nombre"` |
| Nombre duplicado en PUT (otro programa) | `"Ya existe un programa con ese nombre"` |
| UUID inexistente en PUT | `"Programa no encontrado"` |
| UUID inexistente en DELETE | `"Programa no encontrado"` |
| UUID inexistente en GET | `"Programa no encontrado"` |
| Sin token | `403 Forbidden` |
| Token de INSTRUCTOR | `403 Forbidden` |
| state inválido (`BORRADO`) | `400 Bad Request` |
