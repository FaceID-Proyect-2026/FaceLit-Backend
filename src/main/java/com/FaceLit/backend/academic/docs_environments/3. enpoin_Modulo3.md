# Endpoints y JSON de prueba - FaceLit Backend

## Módulo: Programas de Formación

### BASE URL

```text
http://localhost:8080
```

---

# 1. REGISTRAR PROGRAMA

### Endpoint

```http
POST /api/admin/programs
```

### Headers

```text
Authorization: Bearer TOKEN_ADMIN_O_COORDINATOR
Content-Type: application/json
```

### JSON

```json
{
  "programName": "Análisis y Desarrollo de Software",
  "state": "ACTIVE"
}
```

### Respuesta esperada

### HTTP STATUS

```text
201 CREATED
```

### Response

```json
{
  "idProgram": "8b2b4c9d-2c6f-4d58-9d4f-f0f1a95f7f63",
  "programName": "Análisis y Desarrollo de Software",
  "state": "ACTIVE",
  "message": "Programa registrado correctamente"
}
```

# Validaciones a probar

| Caso | Respuesta esperada |
|------|--------------------|
| Nombre duplicado en POST | `"Ya existe un programa con ese nombre"` |
| Nombre duplicado en PUT (otro programa) | `"Ya existe un programa con ese nombre"` |
| UUID inexistente en PUT | `"Programa no encontrado"` |
| UUID inexistente en DELETE | `"Programa no encontrado"` |
| UUID inexistente en GET | `"Programa no encontrado"` |
| Sin token | `403 Forbidden` |
| Token de INSTRUCTOR | `403 Forbidden` |
| state inválido (`BORRADO`) | `400 Bad Request` |

# Flujo Completo de Prueba

## 1. Iniciar sesión como COORDINATOR

Obtiene:

```
TOKEN_COORDINATOR
```

---

## 2. Crear un programa

### Endpoint

```http
POST /api/admin/programs
```

---

## 3. Crear una ficha

### Endpoint

```http
POST /api/admin/chips
```

Guardar el valor generado en:

```
chipCode
```

---

## 4. Iniciar sesión como APPRENTICE

Obtiene:

```
TOKEN_APPRENTICE
```

---

## 5. Unirse a la ficha

### Endpoint

```http
POST /api/apprentice/join-chip
```

Usando el `chipCode` obtenido anteriormente.

---

## 6. Consultar mis fichas

### Endpoint

```http
GET /api/apprentice/my-chips
```

Verificar que la asociación fue creada correctamente.

---

## 7. Iniciar sesión nuevamente como COORDINATOR

Obtiene:

```
TOKEN_COORDINATOR
```

---

## 8. Consultar los aprendices de la ficha

### Endpoint

```http
GET /api/admin/chips/{id}/apprentices
```

Verificar que el aprendiz aparece en el listado.

---

## 9. Desvincular al aprendiz

### Endpoint

```http
DELETE /api/admin/user-chips/{idUserChip}
```

Verificar que la asignación queda inactiva.

---

## 10. Iniciar sesión nuevamente como APPRENTICE

Intentar unirse a otra ficha.

Resultado esperado:

El sistema permite el registro porque la asignación anterior fue desvinculada.

---

# Resumen de Casos de Prueba

| Caso | Resultado esperado |
|------|---------------------|
| Unirse a una ficha correctamente | 201 CREATED |
| Consultar mis fichas | 200 OK |
| Consultar aprendices de una ficha | 200 OK |
| Desvincular aprendiz de una ficha | 204 NO CONTENT |
| Código de ficha inexistente | "El código de ficha no existe o no está activo" |
| Ficha inactiva | "La ficha ya no está disponible para nuevos registros" |
| Aprendiz ya vinculado a otra ficha | "Ya estás vinculado a una ficha activa. Contacta al administrador para desvincular" |
| Código vacío | 400 BAD REQUEST |
| UUID de asignación inexistente | "Asignacion no encontrada" |
| Asignación ya inactiva | "Esta asignacion ya está inactiva" |
| Token APPRENTICE en rutas Admin | 403 FORBIDDEN |
| Token COORDINATOR en rutas Admin | 200 OK |
| Sin token | 403 FORBIDDEN |
