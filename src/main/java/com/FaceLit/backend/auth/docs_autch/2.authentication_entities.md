## Módulo de reconocimiento facial (RF-5)

| Entidad | Descripción | Estado |
|---|---|---|
| FaceRecord | Guarda el encoding facial y la ruta de la imagen del usuario | ⏳ pendiente |

### Atributos de FaceRecord

```
idFaceRecord   PK, UUID
idUser         FK → User
encoding       TEXT — vector numérico de 128 floats generado por Python
imagePath      VARCHAR(255) — ruta de la imagen en almacenamiento externo
activo         BOOLEAN DEFAULT true
─── heredados de AuditBase ───
createdAt      fecha de registro del rostro
updatedAt      última modificación
deletedAt      soft delete
```

**Por qué `encoding` como TEXT:**
Python genera un array numérico que representa el rostro. Se guarda como JSON en texto:
```
[0.1234, -0.5678, 0.9012, ...]
```

**Por qué `imagePath` y no la imagen directa:**
Las imágenes no van en la BD — van en almacenamiento externo (MinIO o carpeta del servidor). En BD solo se guarda la ruta.

**Depende de:** que el login y el registro facial estén implementados.

Construirlas antes sería código sin HU que lo respalde — código basura.
